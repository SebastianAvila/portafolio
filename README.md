# Portfolio

Portafolio personal desarrollado con Next.js, React y TypeScript para presentar mi experiencia, proyectos y habilidades como desarrollador de software.

## 🚀 Tecnologías

Este proyecto fue desarrollado utilizando:

- Next.js
- React
- TypeScript
- Material UI
- GSAP
- Swiper
- EmailJS

## 📦 Instalación

Clona el repositorio:

```bash
git clone https://github.com/tu-usuario/tu-repositorio.git
```

Ingresa al directorio del proyecto:

```bash
cd tu-repositorio
```

Instala las dependencias:

```bash
npm install
```

## 💻 Desarrollo

Para iniciar el servidor de desarrollo:

```bash
npm run dev
```

La aplicación estará disponible en:

```text
http://localhost:3000
```

## 🏗️ Compilación para producción

Genera la versión optimizada para producción:

```bash
npm run build
```

## ▶️ Ejecutar en producción

Después de compilar el proyecto:

```bash
npm run start
```

Este proyecto fue construido tomando como base una plantilla pública de la comunidad open source.

La plantilla fue utilizada únicamente como punto de partida. Posteriormente realicé modificaciones y personalizaciones en distintos aspectos del proyecto, incluyendo:

- Diseño visual
- Estructura de componentes
- Contenido
- Información profesional
- Estilos
- Configuración
- Adaptaciones para mis necesidades y objetivos

El propósito de este repositorio es mostrar mi trabajo, experiencia y proyectos personales como desarrollador.
